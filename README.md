# mii and maa • DAILY HOMECARE

Website landing page modern untuk **mii and maa (DAILY HOMECARE)** - Asuhan kebidanan holistik, gentle birth, hypnobirthing, prenatal yoga, perawatan nifas, dan homecare ibu & bayi.

## 🐘 Fitur Utama
- **Home**: Hero banner dengan identitas mii and maa, nilai utama, dan statistik kepercayaan.
- **Layanan Kami**: Filter terpadu untuk Daily Homecare nifas & laktasi, Kelas Gentle Birth, Hypnobirthing, ANC Holistik, dan Doula 24 Jam.
- **Artikel**: Pusat edukasi medis berbasis bukti + Lead Magnet Checklist Tas Persalinan (Hospital Bag) siap cetak.
- **About Us**: Profil Bidan Annisa Larasati (STR & SIPB Kemenkes aktif, 6 sertifikasi internasional, buku bestseller), kisah kelahiran (*Birth Stories*), dan FAQ.
- **Interaktivitas**: Form reservasi WhatsApp otomatis dan tombol chat WhatsApp mengambang.

## 🛠️ Teknologi
- **Framework**: Vite + React 19 + TypeScript
- **Styling**: Modern Vanilla CSS (Palet warna earth-tone, soft blush & plum)
- **Icons**: Lucide React

## 🚀 Menjalankan Secara Lokal
```bash
# Install dependencies
npm install

# Jalankan dev server
npm run dev

# Build untuk produksi
npm run build
```
